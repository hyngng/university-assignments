## 11주차 수업내용 정리

> 텍스트 분류, 이미지 분류의 관점에서 읽으면 좋음

- CNN
	- 컨볼루젼<sup>Convolution</sup> => 종래의 방법으로는 전체적 경향성만을 파악할 수 있는데, 이 방법은 지역적인, 개별 개성을 파악하기 어려우므로 소규모로 묶어 학습시키는 방법이 있음. 이웃한 데이터간 그룹핑을 거치는 등.
	- 원본 데이터에 필터를 씌워서 가중치와 편향을 구한다는 접근임. 이 때 필터의 사이즈, 값 등도 중요하며, 필터가 어떻게 이동할 것인가가 stride. padding 개념도 적용됨.
		- Max pooling => 가장 중요한 특징을 추출하는 것. (Ex. 얼굴을 볼 때 주요 특징만 추출)
		- Average pooling => 전체적인 특성을 평균적으로 파악.
	- Dense Layer와 CNN의 차이는, 전체에 대한 weight, bias를 구하는 것과 필터를 이동하면서 여러 개 영역에 대해 weight, bias를 구하는 것.
	- 영상처리에서는 필터의 가중치가 미리 결정되는 반면, 딥러닝은 학습하면서 weight가 결정됨. 이 과정을 명확히 설명할 수 없어 블랙박스라고도 불림. 최근 트렌드는 이를 설명하기 위한 eXplainable AI(XAI)임. (= 특징을 명시적으로 추출해서 넣어주는 방법 등)
	- 필터 사이즈는 주로 3x3, 5x5 등으로 정해짐.
		- 28x1 테이블에서 3x1으로 묶으면 검사 경우의 수는 $28 - 3 + 1= 26$가지. Stride = 2일 때 두 칸씩 이동하게 되므로 13 x 13 크기의 결과가 나옴.
	- 고양이 사진을 조금 옮기거나 회전하거나 해서 학습 데이터 증폭 가능 (Data Augmentation)
		- 학습 데이터는 다양해야 하고, 그럼에도 일관되어야 함.

- Transfer Learning
	- 다음의 두 개념이 Transfer Learning을 구성함.
	- Pretrained Network
		- 거대 기업이 잘 학습시켜놓은, 검증된 모델을 가져와서 쓰는 것.
		- 딥러닝의 인풋층에 가까운 곳에서는 일반적인<sup>General</sup> 특징(Ex. 생물이냐 아니냐), 출력층에 가까운 곳에서는 좀 더 구체적인<sup>Specific</sup> 특징(Ex. 무슨 종이냐)을 추출함.
	- Fine Tuning
		- 앞부분의 층 가중치는 가져오고, 뒷부분만 세부 학습시킨다는 접근임. 여기서 뒷부분만 세부 학습(Ex. 앞부분은 객체 인식, 뒷부분은 특정 강아지 종 인식)시키는 과정이 Fine Tuning.
	- 이 두 가지 개념을 포괄하는 것이 Transfer Learning임. 사전학습 네트워크를 불러와 목적에 맞게 마지막 튜닝까지 끝내는 것을 전이학습이라고 함.
