# 2주차

## 주요 개념
- 분류: 데이터의 영역을 범주화하여 미지의 데이터가 속할 클래스를 예측합니다.
- 회귀: $ax + b$의 형태로 최적의 기울기와 절편으로 데이터의 추세를 예측합니다.
- 모델의 일반화: 학습 데이터에 모델이 과적합되는 것을 방지하고 일반화 성능을 높이기 위해 전체 데이터를 훈련용과 테스트용으로 분리합니다.

## 실습 내용
- `classification_breastcancer` 및 `regression_diabetes` 등 분류와 회귀를 코드로 첫 구현했습니다.

# 3주차

## 주요 개념
- 성능 평가지표: 분류 모델은 정확도 및 혼동 행렬로, 회귀 모델은 평균 제곱 오차로 성능을 평가합니다.
- 인공지능의 본질: 전통적인 프로그래밍이 과정과 규칙을 입력하여 결과를 도출하도록 컴퓨터에 위탁하는 반면, 인공지능은 데이터와 결과를 제공하여 그 안의 내재된 과정을 도출합니다.
- K-최근접 이웃: 학습 알고리즘의 일종으로, 특정 데이터를 기준으로 주변의 가장 가까운 이웃 데이터들의 레이블을 참조하여 자신의 레이블을 결정합니다.

## 실습 내용
- `iris` 및 `wine` 데이터셋을 활용하여 각각 다중 분류와 회귀 알고리즘을 코드로 구현했습니다.

# 4주차

## 주요 개념
- 피처 선별: 데이터를 분석하며 모델 성능에 영향을 미치는 주요 피처를 선별하고, 불필요한 노이즈 데이터를 제거합니다.
- 평가 지표의 다각화: 데이터 불균형이 심할 경우 단순 정확도만으로는 모델의 실질적 목적 달성 여부를 파악하기 어려우므로 혼동 행렬으로 다각적으로 평가합니다.

## 실습 내용
- `classification_titanic.ipynb` 실습으로 데이터 전처리를 코드로 다뤘습니다.
    - 데이터 인코딩: `LabelEncoder()` 등을 활용하여 수치형 데이터로 변환했습니다.

# 5주차

## 주요 개념
- 손실 함수: 모델이 예측한 값과 실제 정답 간의 오차를 계산하여 피드백을 제공합니다. 분류 문제에서는 주로 `categorical_crossentropy` 등을 사용합니다.
- 최적화 알고리즘: 경사하강법을 기반으로, 계산된 오차를 바탕으로 가중치를 업데이트하며 점진적으로 최적해를 찾아갑니다.

## 실습 내용
- 유방암, 비만, 와인 관련 `breast_cancer`, `diabetes`, `wine` 데이터셋으로 딥러닝 기반 분류 및 회귀를 코드로 구현했습니다.

# 6주차

## 주요 개념
- 다층 퍼셉트론: 신경망의 기본 구조로 입력층, 은닉층, 출력층으로 구성됩니다.
- 활성화 함수: 선형 연산이 반복되는 신경망에 비선형성을 부여하여 복잡한 패턴을 학습합니다. 대표적으로 ReLU, Sigmoid 등이 있습니다.
- 경사하강법의 종류: 전체 데이터를 사용하는 안정적인 풀 배치 방식과 하나의 데이터를 사용하는 빠른 확률적 경사하강법의 단점을 상쇄한 미니 배치 경사하강법을 사용합니다.

## 실습 내용
- 타이타닉 승객 `abalone` 데이터셋을 활용하여 전복의 나이를 예측하는 회귀 모델과 성별을 분류하는 모델을 각각 구현했습니다.

# 7주차

# 9주차

## 주요 개념
- 기울기 소실: 신경망이 깊어질수록 역전파 과정에서 미분값이 계속 곱해지며, 입력층에 가까워질수록 기울기가 사라져 학습이 진행되지 않는 현상을 뜻합니다.
- 데이터 스케일링: 모델 학습의 안정성을 위해 입력 데이터의 값이 대략 -1에서 1 사이의 범위를 갖도록 정규화합니다.
- 데이터 증강: 훈련 데이터가 부족할 경우, 기존 이미지를 회전, 반전 등으로 변형하여 훈련 데이터셋의 규모를 인위적으로 확장합니다.

## 실습 내용
- 영상 및 이미지 처리를 위한 딥러닝 모델의 수학적 한계점, 이를 극복하기 위한 합성곱 신경망의 기초 개념을 다루었습니다.

# 10주차

## 주요 개념
- 합성곱 신경망: 이미지의 공간적 구조를 파괴하지 않고 합성곱 레이어로 특징을 추출하여 시각적 패턴을 인식합니다.
- 순환 신경망: 과거의 정보가 현재의 연산 결과에 영향을 미치도록 설계되어 시계열 데이터 흐름을 학습합니다.
- 장단기 메모리: 순환 신경망의 장기 의존성 문제를 극복하기 위해 설계된 아키텍처입니다. 셀 상태와 게이트 메커니즘으로 기억을 능동적으로 유지하거나 삭제합니다.

## 실습 내용
- 이 날은 휴일에 보강 수업이 있었고, 실습이 리포트로 대체되었습니다.

# 11주차

## 주요 개념
- 합성곱 신경망의 풀링 연산: 최대 풀링으로 가장 뚜렷한 특징을 추출하고, 평균 풀링으로 데이터의 전체적인 경향성을 보존합니다.
- 전이 학습: 대규모 데이터셋으로 이미 학습이 완료된 네트워크를 가져와 현재 목적에 맞게 세부 조정합니다.
- 사전 학습 네트워크: 대규모 자원을 투입해 검증을 마친 고성능 모델을 뜻합니다.
- 미세 조정: 사전 학습된 모델에서 앞단의 은닉층 가중치는 그대로 유지하고, 최종 목적과 맞닿은 뒷부분의 층만을 새로운 데이터에 맞추어 재학습시킵니다.

# 12주차

# 13주차

## 주요 개념
- 장단기 메모리 메커니즘: 순환 신경망에 셀 개념을 도입하여 입력 게이트, 망각 게이트, 출력 게이트로 단기 및 장기 기억을 능동적으로 제어하고 관리합니다.
- 자연어 전처리: 자연어를 의미를 가지는 최소 단위로 분할하여 토큰화하고, 원-핫 인코딩의 비효율성을 극복하기 위해 단어를 연속적인 고차원 벡터 공간에 할당하는 임베딩을 수행합니다.
- 트랜스포머: 입력 데이터를 순차적으로 스캔하는 방식에서 벗어나, 셀프 어텐션 메커니즘으로 데이터 전체를 한 번에 조망하고 문맥상 중요한 정보에 가중치를 우선 부여합니다.

## 실습 내용
- 시계열 및 자연어 처리에 널리 쓰이는 장단기 메모리의 내부 작동 원리와 텍스트 전처리를 위한 토크나이징을 다루었습니다.
