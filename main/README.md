## **기타 등등**

- `sklearn` => 오픈소스 머신러닝 라이브러리. $y = f(x)$ 구조에서 함수를 제공하는 역할이며, 분류, 회귀 외 여러 기능을 제공함.
    - `sklearn.model_selection`, `sklearn.metrics` 등등

- **logistic regression**: "이 이메일이 스팸일 확률은 92%"처럼 선형 회귀 결과를 시그모이드(Sigmoid) 함수에 통과시켜 0~1 사이의 확률값으로 변환하는 방법.
- **decision tree**: "나이 > 30?" → "소득 > 5000만원?" 처럼 질문을 반복하며 데이터를 트리 구조로 분류하는 방법.
- **random forest**: 결정 트리 여러 개를 만들어 **다수결(또는 평균)**로 최종 결정을 내리는 앙상블 방법
